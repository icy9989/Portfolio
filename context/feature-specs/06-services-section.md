# What I Offer Section

Build a service section that presents the main areas of software development and technology I work with.

The design should follow the provided reference with a clean card-based layout, clear icons, short descriptions, supporting capabilities, and subtle purple gradient accents.

### Section Header

Include:

- small label: `Services`
- main heading: `What I Offer`
- short supporting description

Suggested description:

`Software development services focused on building modern, scalable, and intelligent applications.`

Requirements:

- center the section heading
- highlight `Offer` with the primary purple gradient
- maintain consistent styling in light and dark mode

### Service Cards

Display the services in responsive cards.

Include:

- service icon
- service title
- short description
- 3 supporting capabilities
- subtle hover interaction
- optional `Learn More` link to contact

Use a responsive grid:

- 3 cards per row on large desktop screens where space allows
- 2 cards per row on tablet
- 1 card per row on mobile

### Card Design

Each card should follow the visual style of the provided reference.

Requirements:

- large rounded card
- icon displayed near the top
- clear service heading
- short readable description
- capability list with check icons
- subtle border and shadow
- purple gradient accent or glow
- slightly elevated hover state
- consistent card height where practical
- support both light and dark mode

Avoid excessive colors across cards. Purple should remain the main brand accent.

### Theme

#### Light Mode

- white or light lavender card backgrounds
- soft purple gradients
- dark primary text
- subtle purple-gray borders
- minimal shadows

#### Dark Mode

- near-black or deep-purple card backgrounds
- purple gradient highlights
- light primary text
- muted secondary text
- subtle purple borders and glow

### Animation

Use subtle animation for:

- card entrance
- card hover elevation
- icon interaction
- purple border or glow transition

Avoid excessive movement.

### Responsive Behavior

- cards should reorganize based on screen width
- maintain readable spacing
- capabilities should remain easy to scan
- avoid horizontal overflow
- keep icons and headings proportionally sized on mobile

### Accessibility

- maintain readable contrast
- icons should not be the only indicator of meaning
- interactive elements require visible focus states
- cards should remain understandable without animation

- Robotics card is included
