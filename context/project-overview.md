# Personal Portfolio

## Overview

Personal Portfolio is a responsive developer portfolio website that presents my background, technical skills, education, work experience, and software projects. Visitors can explore my work, view detailed project information, download my resume, and connect with me through professional platforms.

## Goals

1. Introduce myself and my professional background.
2. Present my technical skills and development specialties.
3. Show my education and work experience.
4. Showcase my software projects and detailed project information.
5. Store and retrieve project information using Prisma and PostgreSQL.
6. Provide easy access to my resume, contact information, and professional profiles.

## Core User Flow

1. User opens the portfolio and views my introduction.
2. User navigates between portfolio sections.
3. User learns about my background and technical skills.
4. User explores the development services and areas I specialize in.
5. User reviews my education and work experience milestones.
6. User browses projects loaded from the database.
7. User selects a project and views its details.
8. User can download my resume or connect through GitHub, LinkedIn, or contact options.

## Features

### Header Section

- Responsive navigation between portfolio sections.
- Light and dark mode.
- Mobile navigation.
- Personal introduction, professional title, resume, contact, and social link

### About Me Section

- Personal and professional introduction.
- Main technologies and development background.
- GitHub profile access.

### Skills Section

- Technical skills organized by category.
- Continuously animated skills display.

### What I Offer Section

- Display lists of work that i offer. 

### Milestones Section

- Combined education and work experience timeline.
- Year-based academic and professional milestones.

### Projects Section
- Projects stored in PostgreSQL and accessed using Prisma.
- Project list retrieved through the application API.
- Individual project detail pages.
- Project technologies, descriptions, links, and related information.

### Footer Section

- Contact and professional links.
- navigation access.

## Scope

### In Scope

- Responsive personal portfolio
- Light and dark mode
- About, skills, services, and milestones
- Database-backed project showcase
- Project list and detail pages
- Prisma and PostgreSQL
- Project APIs
- Resume, contact, GitHub, and LinkedIn links

### Out Of Scope

- Mobile-native applications

## Success Criteria

1. Users can navigate all major portfolio sections on desktop and mobile.
2. Light and dark modes work consistently across the website.
3. Projects are successfully stored and retrieved using Prisma and PostgreSQL.
4. Users can browse projects and open individual project details.
5. Resume, GitHub, LinkedIn, and contact options are easily accessible.
